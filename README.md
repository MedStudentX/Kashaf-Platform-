منصة أكاديمية لقراءة المحاضرات والمراجع، تتيح للمستخدم البحث والفلترة الذكية بين المفاهيم باستخدام قواعد المنطق البرمجي (Boolean) للوصول المباشر للمعلومات والتفاصيل المتقاطعة، مع خريطة مفاهيم وملاحظات ومصطلحات بمساعدة الذكاء الاصطناعي. تعمل المنصّة بالكامل محلياً داخل المتصفح، وتبقى بيانات المستخدم على جهازه.

- 🔍 بحث بوليني (AND / OR / NOT) ضمن نص المحاضرة
- 🗂️ خريطة مفاهيم وربط بين الأفكار
- 📝 ملاحظات وتساؤلات لكل محاضرة
- 📁 مكتبة «ملفاتي» — فتح أي محاضرة سابقة دون الحاجة لإعادة رفعها
- 🔒 خصوصية كاملة: لا حساب، وتبقى البيانات لدى المستخدم
